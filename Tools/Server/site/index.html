Playing together

  1. Unzip it anywhere and run WithTheDead.exe (64-bit Windows 10 or 11). If Windows SmartScreen stops it, choose More info → Run anyway.
  2. Make a runner on the title screen.
  3. Under Play together, press Join. The server's address, {{SERVER}}, is already filled in.
  4. In the bar, open the deploy screen from the front door, pick a Zone and press Go. If a raid is already under way, you go into that one.

Updates

The server lets in only the newest build. When a new one is out, the title screen says so: download it here again and replace the old folder. Your runners are kept in %USERPROFILE%\AppData\LocalLow\DefaultCompany\WithTheDead, so they carry over.
