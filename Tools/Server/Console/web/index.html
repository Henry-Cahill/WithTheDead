Release

Builds the game and its server, restarts the server on hts-llm with them and publishes the game on the download page.

Code to send

A GitHub-main build has only what's in git. The radio stations' music (Assets/StreamingAssets/Music, kept out of git because it's gigabytes) comes over from this PC only once main's .gitignore lists it too, that is once main has the radio. Until then main builds go without it, as main's code doesn't play it.

Releases on this PC

These act on the release picked above. Deploy restarts the server with it: a raid under way is lost. Publish uploads its game (about 1.2 GB) to the download page, whose players are then told a new build is out. Push to itch.io sends the game to the itch.io project's windows channel and leaves the download page alone. Check runs Release.ps1 with every step off: it names the release and the address its game joins, and changes nothing.
