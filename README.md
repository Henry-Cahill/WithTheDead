# CLONE-Z
This project is CLONE-Z, a Unity 6 isometric zombie-survival game inspired by Project Zomboid. It aims to combine deep, everyday-life survival simulation, where every door, tap, cupboard and light switch works, with tense extraction raids: loot a snowbound 1993 town and reach an exit before dawn to keep your gear.

## Description
CLONE-Z is set in Knox County in the winter of 1993. The title screen offers two modes:

- **Extraction Raid** (default): Arrive under spawn protection, scavenge a furnished, run-down town, and reach an exit beacon before dawn. Whatever you extract carries over to your next raid. If you die, you lose your kit.
- **Wave Survival**: Fortify the starter house and hold it against escalating zombie waves. Runs can be saved and continued.

Highlights:
- **Survival simulation**: hunger and food sickness, thirst (clean vs. tainted water), sleep, body temperature and clothing, panic, wounds and medical care, skills, crafting, farming, and building/barricading.
- **Interactive world**: doors, windows, kitchens, bathrooms, furniture, storage, car trunks and room lighting all have real actions (E to use, Q for the action menu).
- **Look & feel**: Project Zomboid-style line-of-sight darkness, winter weather, night vision and flashlights, a grid ("Inventory Tetris") inventory with a list view, and a moodle-style HUD. The 45° isometric camera has wall cutaway and can switch to over-the-shoulder or first-person views.
- **Content**: a catalogue of about 3,600 items, plus loot tables and crops, stored in SQLite. More than 3,000 item models were generated by the project's own local-LLM asset pipeline.

**How it's built:** `GameBootstrapper` builds the world, NavMesh, UI and gameplay from code at runtime, so there are almost no hand-built scenes or prefabs. Saves and content use Windows' built-in SQLite (`winsqlite3`). `Tools/` holds three optional utilities:
- **AssetPipeline** generates item models with Ollama (`gpt-oss:120b`) running on a DGX Spark.
- **MapScraper** mirrors zomboidmap.com's Louisville map data for offline reference.
- **NightShift** runs local-LLM coding agents overnight on the DGX Spark (and helper machines) through AI Workbench, working through a task list without cloud AI tokens.

**In development:** a "survival shooter" layer. It adds persistent characters with professions, a hub between raids with traders, a hideout and insurance, and three Zones (Kestrel Flats, Mirelock Woods, The Spillway). The Zones bring anomalies, artifacts, emissions, radiation, roaming NPC squads, mutants and wildlife. The layer also includes a ballistics-based combat rewrite and procedurally synthesized audio.

## Get Started
1. **Install**: You need Windows 10/11 and Unity Hub with editor **6000.7.0a2** (a Unity 6.7 alpha). Open `unityhub://6000.7.0a2/83605ec097c0` to install that exact build. Visual Studio with the *Game development with Unity* workload is recommended; Rider also works.
2. **Clone and open**: Run `git clone https://github.com/Henry-Cahill/CLONE-Z.git`. In Unity Hub, choose **Add → Add project from disk** and select the `CLONE-Z` folder. The first import rebuilds `Library/` and is slow because there are thousands of generated item models.
3. **Play**: Open `Assets/Scenes/SampleScene.unity` and press **Play**. The bootstrapper builds everything and shows the title screen. For raids, pick a runner card's **Play** (or **New runner** on an empty slot or a dead runner's card) to enter the bar, then use the **Door to the Zone** to deploy. For the arena, choose **Wave survival (new)** or **Continue waves**.
4. **Controls**: WASD move · LMB attack · RMB shove · R reload · Shift sprint · Ctrl sneak · E use · Q actions · I inventory · B build · F farm · G water · H health · K skills · T sleep · N night vision · L light · M exits (raids) · V camera view · F5 quick-save (Wave Survival) · Esc pause · F1 toggle key hints.
5. **Save data** is in `%USERPROFILE%\AppData\LocalLow\DefaultCompany\CLONE-Z\`:
   - `clonez_save.db` is the Wave Survival save.
   - `clonez_raid_kit.json` is your extracted raid kit.
   - `clonez_content.db` is the item, loot and crop database.

   The content database is created once and never overwritten. After pulling item changes, delete it so the game rebuilds it from the built-in catalogue.
6. **Optional**: To run the tools, see `Tools/AssetPipeline/README.md`, `Tools/MapScraper/README.md` and `Tools/NightShift/README.md`. The gitignored `ref/` folder is local reference material and isn't needed to build or play.
